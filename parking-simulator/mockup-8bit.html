Design language
A true 8-bit arcade world, not a flat wireframe. Every pixel is a beveled tile with its own highlight and shadow — the same technique that gives the reference art its tactile, chunky depth. A pixel Dubai skyline anchors it to home, the talabat scooter is the hero sprite, and the palette stays disciplined to the brand.

01Beveled pixels, real depth

Each pixel is a tile with a light top-left and dark bottom-right edge. Flat art becomes tactile, exactly like the reference gamepad and lettering.

02A world, not a screen

Parallax Dubai skyline, brick platforms, floating coins, a ? block and a mischief ghost. The frame is alive, not empty.

03Chunky 3D typography

Titles built from beveled blocks with two-tone fills — silver + orange — for that arcade cabinet weight.

04Brand-locked colour

Orange, lime, brown, off-white + one night-plum for atmosphere. No stray hues, no anti-aliasing, ever.

Screen flow
The full journey — title, stage select, dispatch, live HUD, and a Game Over screen that echoes your reference beat-for-beat. Each is rendered live in the pixel engine.
