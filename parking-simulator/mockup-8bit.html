Design principles
Same brand, reinterpreted as a Game Boy-era arcade. Chunky sprites, instant response, four-colour discipline. This is faster to build, easier to iterate on, and it hits a wildly different emotional register — a surprise for a CEO expecting yet another polished 3D demo.

01Four colours, no cheats

Orange, Lime, Brown, Off-white. Dithering only where a mid-tone is unavoidable. Restraint reads as intention.

02Instant everything

No eased curves. Modals appear and disappear. Cursors blink at 60 BPM. Every interaction is one frame.

03Bitmap type only

All headings drawn as canvas pixel glyphs. Body text falls back to a monospaced face — no anti-aliasing.

04Sound is chiptune

Square-wave engine, arpeggio win jingle, one-note failure buzz. WebAudio synthesis, zero samples.

Screen flow
Every screen from the modern direction, reimagined in 8-bit. Same information, same operational story — different vibe.
